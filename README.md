# Catalogo Dirty Task Flipbook

Catalogo web estatico tipo revista digital para Dirty Task.

## Abrir localmente

Abre `index.html` en el navegador. No requiere base de datos ni backend.

## Contenido

- Portada y pagina final con vista de libro cerrado.
- Paginas internas con vista de revista abierta.
- Navegacion siguiente/anterior.
- Indice visual, zoom, autoplay y compartir enlace.
